# Security

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/open-agent-ops/spec/security/advisories/new).
The repository owner must enable and test this channel before public admission.
This source file alone does not establish that the channel is active.

Do not open a public issue containing exploit details, credentials, private
records or customer information. Include affected versions, a synthetic
reproduction and impact. Owners coordinate investigation and a reviewed fix;
disclosure follows the private advisory process.

The offline specification and conformance core grants no runtime or publication
authority. The separate release executable is an explicit protected workflow
capability. CI for pull requests receives no release credential or write
permission. Unexpected host state, mismatched hashes and unknown write outcomes
block publication. Published tags and assets are never overwritten.
